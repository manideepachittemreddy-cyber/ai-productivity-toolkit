# LinkedIn Post — AI Productivity Toolkit

🚀 **Built an AI Productivity Toolkit | Prompt Engineering & AI Productivity**

I worked on a practical toolkit to explore how well-structured prompts can improve everyday AI workflows.

In this project, I practiced:
- Zero-shot and few-shot prompting
- Using roles, context, instructions, constraints, and output formats
- Structured output generation with JSON
- Summarization, classification, email and resume drafting
- AI-assisted coding and debugging
- Reusable prompt templates and a prompt evaluation report

The main takeaway: clear instructions, relevant context, and a defined output format make prompts easier to test and reuse. I also learned the importance of checking AI-generated outputs instead of assuming they are always correct.
